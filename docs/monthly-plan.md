# agentcases.ai 第 1 个月运营目标与实施计划

> 站点地址：https://agentcases-ai.vercel.app/
> 周期：冷启动第 1 个月（第 1 周 ～ 第 4 周）

---

## 一、核心目标（30 天）

| 指标 | 保底目标 | 冲刺目标 | 说明 |
| :--- | :---: | :---: | :--- |
| **累计独立访客（UV）** | **3,000** | **8,000** | 社媒爆款引流 + 长尾搜索开始收录 |
| **日均访问量（UV/天）** | **100** | **300+** | 第 3~4 周形成自然回访与邮件回流 |
| **邮件订阅总数（Newsletter）** | **150 人** | **400 人** | 侧边栏入口 + 第 2 次详情页软拦截（预期 3%~5% 转化率） |
| **每日晨报打开率 / 点击率** | **≥ 45% / ≥ 12%** | **≥ 55% / ≥ 18%** | 早 8:00 推送，5 条精简场景 + 直达 Prompt |

---

## 二、分周实施计划

### 第 1 周：基础设施收口与种子用户冷启动（目标：500 UV / 30 订阅）
- [x] **站内基础与 SEO 就绪**：`llms.txt`、`robots.txt`、动态 `sitemap.xml`、JSON-LD、纯中文 KV 边缘直出。
- [x] **接入轻量访问统计**：集成 `@vercel/analytics` 追踪 UV、来源渠道与热门案例页。
- [x] **GitHub Actions 每日邮件工作流打通**：配置好密钥并验证每日 08:00（UTC+8）自动推送。
- [x] **绑定 Resend 自有发信域名**（避开 `onboarding@resend.dev` 沙盒仅限本人测试的限制，配置 SPF/DKIM/DMARC）。
- [x] **提交搜索引擎收录**：向 Google Search Console 与 Bing Webmaster Tools 提交 `https://agentcases-ai.vercel.app/sitemap.xml`。
- [ ] **种子社区首发**：在海外中文 **X (Twitter)**、**Threads**、**Reddit**（`r/AIAgents`、`r/SideProject`、`r/ClaudeAI`）与国内 **小红书**（手动发图文）发布首发贴（文案见 `docs/week1-launch-posts.md`）。

### 第 2 周：内容切片分发与「发给你的 Agent」裂变（目标：1,500 UV / 100 订阅）
- [ ] **社媒高频切片（每周 4~5 篇）**：从 6 大专题中精选高传播案例，在小红书、即刻、公众号发布图文/短文，文末引导回站内看完整 Prompt 并订阅每日晨报。
- [ ] **「发给你的 Agent」裂变演示**：制作一条 30 秒演示，展示把提示词贴给 Claude / ChatGPT 后自动从 `agentcases-ai.vercel.app` 挑选 5 个定制用例的体验。
- [ ] **每日专题巡检**：每日调用 `GET /api/collections` 检查候选专题，及时审核上线高热度新兴专题（如 `MCP 工具链`、`本地开源模型`）。

### 第 3 周：长尾 SEO 与 AI 目录外链建设（目标：3,000+ UV / 220 订阅）
- [ ] **提交 AI 工具导航站与 GitHub Awesome 列表**：获取高质量反链，提升域权重与搜索引擎抓取频率。
- [ ] **Search Console 关键词复盘**：筛选曝光高但点击偏低的案例/专题词，优化对应专题描述与晨报标题。

### 第 4 周：邮件留存优化与月度复盘（目标：5,000+ UV / 400 订阅）
- [ ] **Newsletter 标题 A/B 优化**：沉淀高打开率公式（`【Agent 晨报】具体数字 + 反常识结果 + 附提示词`）。
- [ ] **主域名绑定评估**：评估绑定独立主域 `agentcases.ai`，提升品牌记忆、SEO 权重与邮件送达率。
